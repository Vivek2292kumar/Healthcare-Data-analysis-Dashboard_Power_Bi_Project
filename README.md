 #Healthcare Data Analysis Dashboard

 
This project showcases a comprehensive healthcare data analysis using an interactive Power BI dashboard. It focuses on patient demographics, hospital performance, treatment efficiency, cost analysis, and future forecasting of patient admissions. The goal is to extract actionable insights that can help healthcare providers improve treatment quality, operational efficiency, and resource planning.

📌 Objective
The primary objective of this project is to analyze patient and hospital data to:

Understand the distribution of patients by gender, age group, and diagnosis.

Evaluate the effectiveness of different treatment types.

Monitor hospital and doctor performance.

Analyze hospital cost breakdowns across different treatment types.

Forecast future patient admissions to aid capacity planning.

🧾 Dataset Overview
The dataset used in this project consists of anonymized healthcare records that include:

Patient Demographics: Gender, Age Group, Diagnosis

Treatment Details: Treatment Type (e.g., Medication, Surgery, Counseling)

Hospital Metrics: Hospital Name, Doctor Name, Costs, Ratings

Temporal Data: Year of admission (2021–2023)

Performance Metrics: Recovery rating, daily cost, total cost
